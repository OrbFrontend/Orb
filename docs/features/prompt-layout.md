# Prompt Layout

**Prompt Layout** in the sidebar sets the order of what the model reads in chat
mode. Drag blocks to reorder them, switch built-in blocks on or off, and add
your own text blocks.

Blocks above **Chat history** go to every pass, so changing them makes the model
re-read the whole chat once. Blocks below it go only to the Writer and are read
fresh every turn, so changing them costs nothing extra.

To use a different arrangement, create or copy a layout, edit it, and press
**Use this layout**.
