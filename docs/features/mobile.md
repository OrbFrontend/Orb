# Mobile Compatibility

Orb's interface adapts to mobile-sized screens. Chat, settings, generation, and
the main writing tools remain available without a desktop browser.

To use Orb from a phone, connect the phone to the same network as the computer
running Orb and open `http://<that computer's IP>:8899`. See
[Network access](../getting-started.md#network-access) for who else can connect
and how to restrict it.
