Library health check
- Separate broken data from optional improvements: a reference to a deleted World is a repair issue; a missing avatar is a completeness suggestion. Avoid treating every sparse card as defective.
- Check completeness: identify empty descriptions, missing opening greetings, placeholder text, and missing public profiles. Let users dismiss fields that are intentionally empty.
- Check linked resources: detect broken World/persona references and unreadable avatar or expression assets. Offer direct links to the relevant settings.
- Check formatting: flag empty alternate greetings, repeated blocks, invisible characters, and unsupported template expressions. Explain the specific issue and show the affected text.
- Check card size: identify unusually long cards and show which fields contribute most. Large size should be informational, with optional suggestions for removing repetition.
- Offer an optional AI review: look for inconsistent names, contradictory character details, or greetings that don’t match the premise. Present quoted evidence and suggestions for review.
- Make results actionable: organize findings by issue type and affected character. Support “Open editor,” “Preview fix,” “Ignore,” and batch application for straightforward fixes.
- Track changes between scans: recheck edited or newly imported cards, retain dismissals, and show which earlier issues have been resolved.
For both tools, I’d use Scan → Review findings → Apply selected changes, with an undo record for every batch operation.
